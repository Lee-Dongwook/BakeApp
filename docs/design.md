# Design Principles & UI Guidelines (`Design.md`)

This document outlines the design principles and UI guidelines to eliminate generic AI-generated design patterns ("AI clichés") and to build a production-grade system with high UX quality and visual sophistication.

---

## 1. Anti-Patterns: Eliminating AI Clichés

Strictly avoid the following repetitive patterns commonly generated by AI design tools:

- **No Purposeful Neon/Purple Gradients:** Ban purple/blue background or CTA gradients that lack clear semantic intent.
- **Remove Excessive Glow & Light Artifacts:** Prohibit neon borders, heavy outer glows, and floating lighting effects applied without contextual cause.
- **Avoid Random 3D Assets:** Ban floating 3D spheres, glossy coins, rounded 3D icons, or decorative elements disconnected from the core content.
- **Reduce Unreadable Glassmorphism:** Restrict low-contrast translucent glass effects. Prioritize solid background surfaces and clear borders for legibility.
- **No Decorative Empty Layout Fillers:** Remove arbitrary stat cards, uncontextualized charts, or decorative dot grids added solely to fill whitespace.

---

## 2. Core Visual Principles

### 2.1 Layout & Grid

- **8pt Grid System:** All spacing, padding, margins, and component dimensions must strictly follow increments of 8px (or 4px for micro-adjustments).
- **Content-Driven Layout:** Content legibility takes priority over decorative frames. Whitespace is an intentional grouping tool, not blank space to be decorated.

### 2.2 Color Architecture

- **60-30-10 Rule:**
  - **60%:** Primary Background & Base Surfaces (Neutral)
  - **30%:** Secondary Content & Structures (Cards, Borders, Subtext)
  - **10%:** Accent & Primary Actions (Strictly reserved for key interactive elements)
- **High Contrast Compliance:** Maintain WCAG 2.1 AA standard contrast ratios (minimum 4.5:1 for standard body text).

### 2.3 Typography

- **Strict Type Scale:** Disallow arbitrary font sizes. Use only predefined typographic tokens (Display, Title, Subtitle, Body, Caption).
- **Line Height & Letter Spacing:**
  - **Body:** `1.5` – `1.6`
  - **Heading:** `1.2` – `1.3`
  - Apply slight tracking/letter-spacing adjustments (`-1%` to `-2%`) for dense or CJK script renderings to maximize readability.

### 2.4 Elevation & Depth

- **Realistic Surface Depth:** Replace heavy drop shadows with 1px subtle borders combined with multi-layered, low-opacity shadows (blur 2–4px) to simulate physical depth cleanly.

---

## 3. Interaction & UX Rules

- **Single Primary Action:** Limit each screen or view to exactly **one** Primary Action CTA. Secondary actions must use Outlined styles, and tertiary actions should remain Text-only.
- **Complete State Coverage:** Every interactive component must explicitly define `Hover`, `Active`, `Focus`, `Disabled`, and `Loading` states.
- **Purposeful Micro-interactions:** Limit transitions to 200ms–300ms. Prohibit continuous looping animations (e.g., perpetual pulsing or spinning) that cause cognitive distraction.

---

## 4. Design System Tokens

### Spacing Scale

```
4px   - xxs (micro)
8px   - xs  (compact)
16px  - sm  (default padding)
24px  - md  (section gap)
32px  - lg  (container gap)
48px+ - xl  (page margin)
```

### Radius Scale

```
2px / 4px - Small (Checkboxes, Badges)
8px       - Medium (Buttons, Inputs, Standard Cards)
12px      - Large (Modals, Featured Cards)
9999px    - Full (Pills, Avatars)
* Ban excessive rounded corners (>24px) unless explicitly justified by pill geometry.
```

---

## 5. Review Checklist

Designs must pass all checklist criteria before code merge:

- [ ] Are there any neon glows or light artifacts that scream "AI-generated"?
- [ ] Is every alignment and spacing strictly aligned to the 8pt grid?
- [ ] Does text contrast pass WCAG AA standards without visual fatigue?
- [ ] Is the single Primary Action visually distinct and unambiguous?
- [ ] Are all non-functional decorative graphics completely removed?
